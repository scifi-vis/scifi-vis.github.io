Conference Workshop site for SciFi-Vis at IEEE VIS 2026!

Want to use/extend this for your own? 
- `npm install` brings all dependencies. 
- `npm run dev` enables http://localhost:3000/ 
- `npm run build` creates static files on `./dist`. This folder is gitignored on purpose. 
  - To test locally, use `npm install serve --global` and `serve -p 3000`. 
  - To deploy to Github Pages:
  - Move the contents of `/dist` to the `deploy` branch, commit and push.
